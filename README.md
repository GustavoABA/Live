# NihilGuh Wonderland Broadcast

Este repositório contém dez cenas de live em HTML/CSS/JS para uso como Browser Source no OBS e publicação via GitHub Pages. A direção visual combina Alice no País das Maravilhas em versão VTuber anime com uma abordagem mais agressiva: roxo pastel, lilás, preto, branco, contraste alto, molduras fortes e objetos de cenário distribuídos como uma composição real de OBS.

## Cenas

`0-iniciando` · `1-entrada` · `2-chat` · `3-gameplay` · `4-reacts` · `5-intermissao` · `6-colabs` · `7-ja-volto` · `8-final` · `9-emergencia`

Cada cena possui layout próprio para a função correspondente. A cena `2-chat` é um ambiente de tea party com mesa, xícaras, cartas, relógio, rosa, chave, cogumelo, chat separado e evento visual automático a cada 10 minutos. As telas de entrada, reações, colaborações e final têm molduras e áreas funcionais distintas para câmera, chat, vídeo e convidados.

As animações usam GSAP via CDN e CSS. Os fundos públicos de castelo noturno estão em `assets/`, com referências em `assets/README.md`. O canal é **NihilGuh**.

Abra qualquer pasta como Browser Source no OBS. O GitHub Pages usa a branch `main` e a pasta `/ (root)`.
