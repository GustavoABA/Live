# Ilustração Adam

O arquivo `adam-base64.txt` contém uma prévia compacta e transparente do personagem enviado, em AVIF codificado como base64. O script `../character.js` a carrega automaticamente nas dez cenas e no painel.

Para maior resolução, adicione `adam.webp` nesta pasta. O carregador prefere `adam.webp` e usa a prévia apenas se o WebP não estiver disponível. O fundo verde da imagem enviada deve ser removido antes de usar no OBS.
